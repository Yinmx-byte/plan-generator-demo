# RDS/DRDS 检修

## 资源表

- 创建 RDS：实例名称、实例规格、存储空间、芯片架构、数据库类型、数据库版本、VPC、VSwitch、白名单、数量、环境。
- 规格/磁盘变更：实例名称、实例 ID、当前规格、目标规格、环境。
- 参数调整：实例名称、实例 ID、参数名、当前值、目标值、环境。

## 实施步骤

- 创建：确认版本、规格、存储、网络、白名单，创建后检查运行状态和连接。
- 参数调整：记录原参数，确认生效方式和是否重启，修改后检查实例状态和业务。
- 升配/降配/扩容：检查备份、监控、连接数和业务窗口，执行变更后验证数据库状态。
- 回收：确认无业务连接、备份完成、项目组确认后释放实例。

## 风险与回滚

- 参数调整可能影响业务性能或连接，必须保留原值。
- 扩容通常不影响业务；降配可能影响性能，必须说明容量风险。
- 回收类操作风险最高，必须强调清单复核和备份。
