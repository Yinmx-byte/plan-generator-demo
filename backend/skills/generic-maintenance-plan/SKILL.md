# 通用检修方案 Skill

用于没有专门类型 Skill 覆盖的检修事项。

## 章节规则

- 保留基础七章结构。
- 实施步骤按用户描述展开，不要凭空编造具体平台按钮。
- 风险评估使用授权、备份、验证、双人复核四类危险点。

## 内容规则

- 创建类操作通常对业务无影响，备份可写“不涉及备份”。
- 配置变更类操作需要写明变更前确认、变更后验证和回退方式。
- 如果用户没有提供回退方式，写“按变更前配置恢复，并联系项目组验证业务正常”。
