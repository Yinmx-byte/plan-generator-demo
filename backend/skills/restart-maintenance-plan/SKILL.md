# 维护性重启 Skill

## 适用场景

- ECS 维护性重启。
- K8s worker 节点重启。
- 需要排水、设置不可调度、恢复调度的重启流程。

## 文档结构补充

实施步骤必须包含：

- 检修前检查快照或备份正常。
- 检查业务冗余和单点风险。
- 如为 K8s 节点，先设置不可调度并排空节点。
- 执行重启。
- 重启完成后检查节点、实例、系统组件或 Pod 状态。
- 恢复调度。
- 联系项目组验证业务。

如用户提供重启节点参数，在文末追加 `维护性重启节点参数表`，使用 `table` 块。

## 风险与回滚

- 重启类检修可能造成短暂中断，需明确影响范围。
- 备份/快照检查必须写入。
- 重启通常不涉及回退；回滚章节写“重启实例不涉及回退，若异常则按应急预案恢复或联系平台支持处理”。
