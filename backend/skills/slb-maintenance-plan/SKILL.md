# SLB 检修

## 使用方式

本 Skill 是 SLB 检修方案的业务结构来源。后端只提供通用 JSON 渲染和 DOCX 生成工具，不再为 SLB 单独补写风险项、实施步骤或回滚步骤。因此生成方案时必须在本文件中读取并执行下列章节、风险和步骤规则。

## 适用场景

- 创建 SLB 实例：内网 SLB、外网 SLB、IPv6 类型 SLB。
- 调整监听或后端服务器组：监听端口、协议、健康检查、后端服务器组成员。
- 回收空闲 SLB 实例：确认无业务流量、解绑关联、释放实例。
- SLB 单点故障演练：监听后端服务器组切流、恢复、监控和退出条件。

## 资源字段

创建 SLB：

- 实例名称、网络环境、内网/外网类型、IPv6 类型、VPC、VSwitch、规格、协议、监听端口、后端服务器组、健康检查配置、所属系统、业务确认人。

监听/后端服务器组调整：

- SLB 实例名称、实例 ID、监听端口、监听协议、当前后端服务器组、目标后端服务器组、健康检查方式、原配置截图或导出记录。

回收 SLB：

- SLB 实例名称、实例 ID、网络类型、绑定业务、监听列表、后端服务器组、DNS/域名/业务入口引用情况、项目组确认人。

单点故障演练：

- 演练对象、监听端口、后端服务器组、切流对象、恢复对象、监控指标、退出条件、项目组验证人。

## 风险评估规则

`5.1影响范围` 必须写明：

- 是否影响业务访问；
- 涉及的系统、SLB 实例、监听端口、后端服务器组；
- 创建类检修通常不影响存量业务，但要说明新资源配置错误的影响；
- 回收类检修必须说明误删或仍有流量时会造成业务不可访问；
- 单点故障演练必须说明切流期间的访问抖动、健康检查异常和恢复风险。

`5.2危险点分析` 必须围绕 SLB 对象写具体风险：

- VPC、VSwitch、内网/外网类型或 IPv6 类型选择错误；
- 监听协议、端口、健康检查配置错误；
- 后端服务器组配置错误或成员缺失；
- 回收前未确认监听、后端、DNS、业务入口是否仍被使用；
- 单点故障演练切流对象、恢复对象或退出条件不清。

`5.3安全措施` 必须包含：

- 5.3.1授权：说明 ASCM/堡垒机账号授权、操作权限、工单或项目组确认。
- 5.3.2备份：记录原 SLB 配置、监听配置、后端服务器组、健康检查、DNS/业务引用；创建类记录目标配置。
- 5.3.3验证：检修前后分别验证监听状态、健康检查、后端服务器组、业务访问。
- 5.3.4 双人复核：关键配置、释放实例、切流/恢复动作必须双人复核。

## 实施步骤规则

`6.1备份`：

- 创建类：备份需求参数、目标 VPC/VSwitch、协议、端口、后端服务器组、健康检查配置。
- 调整类：备份原监听、原后端服务器组、健康检查配置和业务访问结果。
- 回收类：备份实例详情、监听列表、后端服务器组、DNS/域名/业务入口引用情况。
- 演练类：备份演练前监听状态、后端健康状态、业务访问和监控基线。

`6.2 检修前验证`：

- 登录 ASCM 或对应云平台控制台。
- 查询目标 SLB 实例或待创建参数。
- 验证监听、后端服务器组、健康检查、业务访问、监控状态。
- 回收类必须确认实例为空闲且业务方确认无流量。

`6.3 检修操作` 必须按动作写可执行步骤：

- 创建 SLB：进入负载均衡控制台，选择内网/外网或 IPv6 类型，选择 VPC、VSwitch、规格，创建实例，配置协议和监听端口，绑定后端服务器组，配置健康检查。
- 调整监听/后端：进入目标 SLB，记录原监听配置，调整监听协议/端口或后端服务器组，保存后观察健康检查。
- 回收 SLB：确认监听、后端服务器组、DNS/业务入口均无引用，项目组确认后释放实例。
- 单点故障演练：按演练方案切换后端服务器组或模拟单点，观察监控和业务访问，达到退出条件后恢复原配置。

`6.4 检修后验证`：

- 验证 SLB 实例状态、监听状态、健康检查状态。
- 验证后端服务器组成员正常。
- 验证业务访问链路、监控指标和项目组确认结果。
- 创建 IPv6 SLB 时必须验证 IPv6 地址、监听、业务访问和安全策略。

## 回滚规则

`7.1 回滚操作`：

- 创建类：如新建 SLB 未投入业务，可删除新建监听、后端服务器组绑定或释放新实例；如已投入业务，先恢复业务入口再清理。
- 调整类：恢复原监听协议、端口、后端服务器组和健康检查配置。
- 回收类：若已释放且平台不支持恢复，写明需要按备份配置重新创建 SLB、监听和后端服务器组。
- 演练类：恢复原后端服务器组、监听配置和流量路径。

`7.2 回滚后验证`：

- 复查监听、后端服务器组、健康检查、业务访问、监控指标。
- 由项目组确认业务恢复。

## 禁止事项

- 不要只写“检查配置”“按实际情况处理”等空泛语句。
- 不要编造不存在的控制台菜单；不确定时写“进入负载均衡/SLB 控制台的对应实例详情页”。
- 不要省略备份、检修前验证、检修操作、检修后验证、回滚操作、回滚后验证。
