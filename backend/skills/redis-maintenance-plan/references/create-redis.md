## 四、与当前 `generate_plan.py` 的关键差异

| 位置 | 当前脚本写法 | 模板实际写法 | 影响 |
|------|-------------|-------------|------|
| 6.3 操作步骤 | 拆成多段编号步骤 `1、2、3、...` | **一个完整自然段** + 两个不编号段落 | 语言风格不同 |
| 6.3 操作描述 | `登陆 ASCM 平台` | `登陆{内外网}云ASCM平台` | 缺少网络前缀 |
| 6.3 操作描述 | `{org_str} → {rs_str}` | `选择组织"{org}"-资源集"{resource_set}"` | 连接方式和措辞不同 |
| 6.3 编号 | 从 1 开始编号 | **无编号**，纯自然段 | 格式不同 |
| 6.4 结尾 | `验证...业务正常。`（句号） | `验证...业务正常；`（分号） | 标点符号 |
| 7.1 第一行 | `1、{title}回退` | 一致 | — |
| 7.1 第二行 | `（1）删除新建redis实例` | `删除新建redis实例`（无编号） | 多了不必要的编号 |
| 7.2 结构 | 合并为一段 | 拆为两段（标题行 + 验证描述行） | 结构不同 |

## 五、"创建"操作的几个关键约定

1. **备份描述：** 创建操作不涉及备份，全文三处一致（5.3.2 安全措施备份、6.1 备份、如有其他引用处），均使用"{title}不涉及备份"。
2. **验证描述：** 创建前验证资源集IP充足（默认），或验证实例运行正常（视项目而定）。
3. **操作动词：** 使用"创建实例"，不是"新建实例"。
4. **回退动词：** 使用"回退"（模板用语），"回滚"仅用于章节标题。
5. **6.3.1 小标题：** 始终为"创建redis实例"，不拼接完整 project title。
6. **操作描述使用自然段落，不拆分编号。** 这是与升配/降配等其他操作类型最大的语言风格区别。
