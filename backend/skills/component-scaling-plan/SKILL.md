# 组件扩缩容 Skill

## 适用场景

- ECS、数据库、MongoDB 或其他云组件规格调整。
- 扩容、缩容、节点数调整、存储扩容。

## 文档结构补充

实施步骤必须包含：

- 检修前确认当前规格、目标规格和资源配额。
- 检查是否存在单点风险。
- 执行变更配置或扩缩容操作。
- 等待任务完成并检查组件状态。
- 联系项目组验证业务。

## 风险规则

- 扩容通常对业务无影响，但仍需验证业务连接和资源状态。
- 缩容可能影响容量或冗余能力，必须说明风险和验证方式。
- 规格变更如涉及重启，需同时遵循重启 Skill。

## 回滚规则

- 可回退的规格变更，写明恢复原规格。
- 不支持直接回退的扩容，写明“不涉及回退”或“按平台能力重新调整至原配置”。
